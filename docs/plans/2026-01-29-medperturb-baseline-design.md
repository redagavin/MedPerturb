# MedPerturb Calibrated Baseline Design

**Date:** 2026-01-29
**Goal:** Add calibrated baselines to MedPerturb to distinguish perturbation-specific effects from general text-change effects.

---

## Overview

The original MedPerturb dataset contains 800 rows:
- 200 originals (dataset_id=1)
- 200 gender-swap perturbations (dataset_id=2)
- 200 gender-remove perturbations (dataset_id=3)
- 100 uncertain perturbations (dataset_id=4)
- 100 colorful perturbations (dataset_id=5)

We add 600 calibrated baselines (one per perturbation), where each baseline:
- Is a paraphrase of the original clinical context
- Matches the token change % of its corresponding perturbation (per-sample matching)
- Contains no semantic changes (no gender swap, no stylistic change)

This allows us to answer: "Did the model's answer change because of the specific perturbation (e.g., gender swap), or just because the text changed?"

### Linking logic

Each baseline row is linked to:
- Its **original** via `(dataset, context_id, dataset_id=1)`
- Its **corresponding perturbation** via `(dataset, context_id, dataset_id=N)` where N ∈ {2,3,4,5}

### Step 4: Analysis (Bootstrap MI Test)

**Input:** `data_with_baselines.csv` with all model outputs
**Output:** Statistical comparison of perturbation vs baseline effects

**MI calculation (from original notebook):**
```python
def calculate_mi(x, y):
    """Mutual information between two arrays."""
    joint = pd.crosstab(x, y, normalize=True)
    p_x = joint.sum(axis=1)
    p_y = joint.sum(axis=0)
    mi = 0
    for i in joint.index:
        for j in joint.columns:
            if joint.loc[i,j] > 0:
                mi += joint.loc[i,j] * np.log2(joint.loc[i,j] / (p_x[i] * p_y[j]))
    return mi
```

**Bootstrap hypothesis test (new):**
```python
def bootstrap_mi_test(orig, pert, base, n_bootstrap=1000):
    """
    Bootstrap hypothesis test: is MI(orig,pert) different from MI(orig,base)?
    """
    n = len(orig)
    diffs = []

    for _ in range(n_bootstrap):
        indices = np.random.choice(n, n, replace=True)
        mi_pert = calculate_mi(orig.iloc[indices], pert.iloc[indices])
        mi_base = calculate_mi(orig.iloc[indices], base.iloc[indices])
        diffs.append(mi_pert - mi_base)

    observed_diff = calculate_mi(orig, pert) - calculate_mi(orig, base)
    ci_low, ci_high = np.percentile(diffs, [2.5, 97.5])

    # Two-tailed p-value
    if observed_diff >= 0:
        p_value = min(np.mean(np.array(diffs) <= 0) * 2, 1.0)
    else:
        p_value = min(np.mean(np.array(diffs) >= 0) * 2, 1.0)

    return {
        'mi_perturbation': calculate_mi(orig, pert),
        'mi_baseline': calculate_mi(orig, base),
        'observed_diff': observed_diff,
        'ci_low': ci_low,
        'ci_high': ci_high,
        'p_value': p_value
    }
```

**Analysis loop:**
```python
for perturbation_type in ['gender_swap', 'gender_remove', 'uncertain', 'colorful']:
    for model in ['LLAMA3', 'LLAMA3-70']:
        for task in ['MANAGE', 'VISIT', 'RESOURCE']:
            orig = get_responses(dataset_id=1, model, task)
            pert = get_responses(dataset_id=type_to_id[perturbation_type], model, task)
            base = get_responses(dataset_id=type_to_id[perturbation_type]+4, model, task)

            result = bootstrap_mi_test(orig, pert, base)
```

**Interpretation:**
- If CI excludes 0 → statistically significant difference between perturbation and baseline
- If MI_perturbation > MI_baseline → perturbation has specific effect beyond general text changes
